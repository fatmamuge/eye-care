# 👀 EyeCare

A simple eye break reminder for Ubuntu written in Python.

EyeCare helps reduce eye strain by reminding you to take regular breaks while working on your computer.

## Features

- ⏰ Reminds you every 20 minutes
- 👀 Shows a simple eye break window
- 🪶 Lightweight and easy to use
- 🐍 Written in Python with Tkinter
